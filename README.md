# ELYSIUM — interfaz preliminar

## Abrir localmente
Abre `index.html` en un navegador. Los tres archivos deben permanecer en la misma carpeta.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `style.css` y `script.js` a la raíz.
3. En Settings → Pages, selecciona Deploy from a branch, `main` y `/ (root)`.
4. Guarda y espera la publicación.

## Estado del prototipo
- Navegación lateral funcional.
- Página principal y apartados preliminares.
- Mapa esquemático interactivo con selector de cuatro niveles.
- Nodos seleccionables con panel informativo.
- Controles para rutas y retícula.
- Diseño adaptable a móvil.

El mapa es un esquema conceptual, no un plano arquitectónico validado. Las posiciones, rutas, dimensiones, entradas secundarias y contenido de los niveles deben revisarse con el lore y las decisiones posteriores. Los contenidos no confirmados están identificados como propuestas o pendientes.
